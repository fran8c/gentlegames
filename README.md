# Gentle Games by FC · 温和小游戏

A free collection of six calm, browser-based activities for people living with mild to moderate dementia and those who support them, in English and Mandarin (中文).
No scores, timers or wrong answers. No accounts, ads or tracking. Everything a family adds stays on their own phone.

**Play:** https://fran8c.github.io/gentlegames/

| Game | Folder | What it is |
|---|---|---|
| Window Seat · 窗边小憩 | `window-seat/` | A calm window: koi pond, garden, train ride or rain. Touch and it answers gently. |
| Little Chores · 家务小帮手 | `little-chores/` | Short, familiar jobs that can always be finished. |
| Radio Days · 怀旧电台 | `radio-days/` | An old radio with big station buttons and familiar songs. |
| Spot It! · 找一找 | `spot-it/` | Find one thing at a time in a familiar local scene. |
| Photo Album · 相册·旧时光 | `photo-album/` | Family photos and old scenes, with names and family voices. |
| Memory Garden · 记忆花园 | `memory-garden/` | A few everyday facts, brought back gently. Each answer grows a flower. |

## What is in this folder

- `index.html`: the landing page (introduction, the six games, how to start).
- One folder per game, each holding a single self-contained `index.html`.
- `img/`: the game pictures used on the landing page.
- `favicon.svg`, `og.png`: the site icon and the picture shown when the link is shared.

Each game is one file with everything inside it, so nothing else needs installing. The games share a few settings (language, level, high contrast, online voice) because they sit on the same web address.

## Updating a game

Replace that game's `index.html` inside its folder, keeping the folder name. The landing page does not need to change.

## Notes

- For comfort and engagement, not treatment. Not medical advice.
- The only network use during play is Radio Days, when a station plays from a Spotify or YouTube link.
- Theme tunes are original melodies.
